什么是大语言模型 LLM：从 RNN、LSTM 到 Transformer 的入门笔记

发表于2026-06-17|更新于2026-06-17|AI

前言

这篇文章整理我对 大语言模型 LLM 的入门理解。

一开始我只知道 LLM 可以生成、分类、改写和总结文本。后来我发现，想真正理解 GPT 这一类模型，就需要继续往下看它背后的结构。GPT 背后最关键的技术之一是 Transformer。

Transformer 又涉及几个核心概念：

  • Token；
  • Embedding；
  • Positional Encoding；
  • Self-Attention；
  • Multi-Head Attention；
  • Encoder；
  • Decoder；
  • Linear；
  • Softmax；
  • Output Probabilities。

在 Transformer 流行之前，处理序列数据经常会用到 RNN。后来 RNN 被改良为 LSTM，用来缓解长序列信息丢失的问题。再后来，Transformer 因为更适合长距离关系建模和并行训练，逐渐成为现代大语言模型的重要基础。

一、什么是大语言模型 LLM？

LLM 的全称是 Large Language Model，中文通常叫 大语言模型。

它是一类通过大量文本数据训练出来的模型。它可以处理自然语言，也可以生成自然语言。

这里的“语言”不只包括中文、英文这样的自然语言，也可以包括代码、表格、公式、结构化文本和指令。

简单来说：

大语言模型是一种能够根据上下文理解和生成文本的 AI 模型。

模型会根据输入内容和上下文，生成一段总结。

二、LLM 的常见能力

LLM 最常见的能力包括：

能力 含义 例子
生成 根据提示写出新内容 写文章、写邮件、写代码
分类 判断文本属于哪一类 判断评论是正面、负面还是中立
改写 保留原意，换一种表达方式 把复杂句改成简单句
总结 提取重点，压缩内容 把长文总结成短文
翻译 在不同语言之间转换 中文翻译成英文
问答 根据问题生成回答 回答学习问题或工作问题
信息提取 从文本中抽取关键信息 提取姓名、时间、地点、金额

其中，生成、分类、改写和总结是最容易理解的四种能力。

四、GPT 背后有 Transformer

学习 LLM 时，一个重点是：

GPT 背后有 Transformer。

GPT 的全称是 Generative Pre-trained Transformer。

可以拆开理解：

词 含义
Generative 生成式，说明它可以生成内容
Pre-trained 预训练，说明它先在大量文本上学习语言规律
Transformer 模型架构，说明它基于 Transformer 结构

所以，GPT 的名字本身就说明了它的技术路线：

GPT 是一种基于 Transformer 架构的生成式预训练语言模型。

不过这里要注意一个细节：

原始 Transformer 由 Encoder 和 Decoder 组成；GPT 主要使用的是 Decoder-only Transformer，也就是只使用解码器部分的 Transformer 架构。

所以，当我们说“GPT 背后有 Transformer”时，不能简单理解为 GPT 完整照搬了原始 Transformer 的 Encoder-Decoder 结构。更准确的说法是：

GPT 使用了 Transformer 的核心思想，尤其是自注意力机制和位置编码，并采用了偏生成任务的 Decoder-only 架构。

六、RNN：循环神经网络

RNN 的全称是 Recurrent Neural Network，中文叫 循环神经网络。

RNN 适合处理序列数据。比如：

  • 文本；
  • 语音；
  • 时间序列；
  • 股票价格；
  • 用户行为序列。

RNN 的核心思想是：

七、为什么 RNN 不擅长长序列？

RNN 看起来很适合处理语言，因为语言本来就是有顺序的。但 RNN 有一个明显问题：

它不擅长处理很长的序列。

原因主要有三个。

1. 长距离信息容易丢失

如果一句话很长，前面的信息要经过很多步才能传到后面。传递次数越多，信息越容易变弱。

比如：

这里的“它”指的是“书”。但是“书”和“它”之间隔了很多词。普通 RNN 可能很难稳定保留这个远距离关系。

2. 容易出现梯度消失或梯度爆炸

RNN 在训练长序列时，容易遇到梯度问题。

简单理解：

  • 梯度消失：重要信息传到前面时越来越弱，模型学不到长期关系；
  • 梯度爆炸：数值变得太大，训练变得不稳定。

3. 并行能力弱

RNN 是按顺序处理的。后一个 token 往往要等前一个 token 处理完才能继续。

这会导致训练速度比较慢，不适合非常大规模的数据训练。

所以可以总结为：

RNN 可以处理序列，但不擅长长序列，也不适合大规模并行训练。

八、LSTM：RNN 的改良版

LSTM 的全称是 Long Short-Term Memory，中文通常叫 长短期记忆网络。

LSTM 是 RNN 的一种重要改良。它的目标是缓解 RNN 不擅长长序列的问题。

LSTM 加入了“门控机制”，让模型可以决定：

  • 哪些旧信息需要遗忘；
  • 哪些新信息需要写入；
  • 哪些信息需要输出。

LSTM 常见的三个门是：

门 作用
遗忘门 Forget Gate 决定哪些旧信息要丢掉
输入门 Input Gate 决定哪些新信息要写入记忆
输出门 Output Gate 决定当前要输出哪些信息

不过，LSTM 仍然是按顺序处理序列。因此，它虽然比普通 RNN 更强，但在大规模并行训练方面仍然不如 Transformer。

九、Transformer 为什么出现？

Transformer 的出现，是为了解决传统序列模型的一些问题。

RNN 和 LSTM 都是按顺序处理文本。它们有一个共同特点：

而 Transformer 的核心变化是：

它不再完全依赖循环结构，而是通过注意力机制直接建模 token 之间的关系。

这带来两个重要优势：

  1. 更适合捕捉长距离依赖；
  2. 更适合并行计算。

所以，现代大语言模型大量采用 Transformer 结构。

5. Multi-Head Attention：多头自注意力

进入编码器后，模型会使用 Multi-Head Attention。

在 Encoder 里，这个注意力通常是 多头自注意力。

自注意力机制的作用是：

模型在处理每个 token 时，不只看它自己，也会看序列中其他 token，并判断哪些 token 更重要。

比如：

模型处理“它”时，需要判断“它”可能指“书”还是“书包”。这时它会关注句子中其他词之间的关系。

多头注意力中的“多头”可以理解为：

模型从多个角度同时观察 token 之间的关系。

有的头可能关注语法关系，有的头可能关注指代关系，有的头可能关注语义相关性。

6. Add & Norm：残差连接和归一化

注意力层之后会经过 Add & Norm。

它包含两个思想：

  • Add：把这一层的输入和输出相加，也叫残差连接；
  • Norm：对结果进行归一化，让训练更稳定。

简单理解：

Add & Norm 可以帮助深层网络更稳定地训练，也能减少信息在多层传递中丢失的问题。

然后会进入 Feed Forward 层。

8. Encoder 输出

经过多层 Encoder 后，输入文本会被转换成更抽象的向量表示。

这个表示包含：

  • 词汇信息；

  • 语法关系；
  • 语义关系；
  • 上下文信息。

可以理解为：

Encoder 把原始输入文本压缩和转换成模型更容易使用的抽象表示。

十四、GPT 为什么常被说成 Decoder-only？

前面讲的是原始 Transformer 的 Encoder-Decoder 架构。

但是 GPT 不是完整使用 Encoder + Decoder 的结构。

GPT 主要使用 Decoder-only Transformer。

这意味着 GPT 更关注一件事：

根据已经出现的上下文，预测下一个 token。

它的结构更适合生成任务。

可以简单理解为：

    Token --> Embedding[Token Embedding + Positional Encoding]
    Embedding --> MaskedAttention[Masked Self-Attention]
    MaskedAttention --> FFN[Feed Forward]
    FFN --> Linear[Linear]
    Linear --> Softmax[Softmax]
    Softmax --> NextToken[下一个 Token]
    NextToken --> Continue[继续生成]

十五、自注意力机制 Self-Attention

自注意力机制 的英文是 Self-Attention。

它的核心问题是：

处理一个 token 时，模型应该关注序列里的哪些其他 token？

比如：

这里的“它”可能指“猫”，也可能指“垫子”。模型需要通过上下文判断。

自注意力机制会让每个 token 和其他 token 建立联系，并计算它们之间的重要程度。

可以简单理解为：

自注意力机制的价值在于：

  • 它可以建立远距离词之间的联系；
  • 它可以动态决定关注重点；
  • 它比 RNN 更容易并行计算；
  • 它适合处理复杂上下文。

十六、多头注意力 Multi-Head Attention

Multi-Head Attention 是多个注意力头并行工作。

单个注意力头只能从一个角度关注文本关系。多个注意力头可以从不同角度学习关系。

例如：

  • 一个头关注主语和谓语；
  • 一个头关注代词指代；
  • 一个头关注长距离依赖；
  • 一个头关注句子结构；
  • 一个头关注语义相关性。

所以，多头注意力可以让模型获得更丰富的上下文表示。

简单理解：

Self-Attention 是注意力机制；Multi-Head Attention 是多个注意力机制一起工作。

十八、为什么模型会出现幻觉 Hallucination？

你笔记里提到：

解码器本质上是猜下一个最有可能的输出，所以模型可能胡说八道，这也叫幻觉 hallucination。

这个理解方向是对的。

LLM 在生成文本时，通常是在根据上下文预测下一个 token。它的目标是生成“看起来最合理”的内容，而不一定保证每一句话都是真的。

所以，幻觉可以理解为：

模型生成了语法通顺、看起来可信，但事实错误或没有依据的内容。

幻觉出现的原因很多，比如：

  • 训练数据中可能有错误；
  • 模型不知道自己不知道；
  • 用户问题缺少足够上下文；
  • 模型为了保持回答连贯，会继续生成看似合理的内容；
  • 生成过程本身是概率性的。

所以使用 LLM 时，尤其在事实、医学、法律、金融、学术引用等场景中，需要进行核查。

RNN 按顺序循环处理序列 结构直观，适合序列数据 长序列信息容易丢失，并行能力弱
LSTM 在 RNN 上加入门控记忆 比 RNN 更擅长保留长期信息 仍然按顺序处理，训练效率有限
Transformer 用注意力机制建模 token 关系 长距离建模强，并行能力强 计算量大，需要较多数据和算力
GPT Decoder-only Transformer 擅长文本生成和对话 可能产生幻觉，需要事实核查

二十一、用一句话总结每个概念

概念 一句话理解
LLM 大规模训练出来的语言模型，可以理解和生成文本
GPT 基于 Transformer 的生成式预训练语言模型
Transformer 一种基于注意力机制的深度学习架构
Encoder 负责理解输入文本，并生成抽象表示
Decoder 负责根据上下文生成输出文本
Token 模型处理文本的基本单位
Token ID Token 在词表中的整数编号
Embedding 把 token id 转换成语义向量
Positional Encoding 给 token 加入顺序信息
Self-Attention 让 token 关注同一句话中其他 token
Multi-Head Attention 从多个角度同时计算注意力
Masked Attention 遮住未来信息，保证从左到右生成
Linear 把模型输出映射成词表大小的分数
Softmax 把分数转换成概率分布
Hallucination 模型生成了看似合理但事实错误的内容
RNN 按顺序处理序列的循环神经网络
LSTM 加入门控记忆机制的改良版 RNN

二十二、最终总结

这篇笔记可以压缩成一条主线：

如果用一句话总结：

大语言模型不是简单背答案，而是通过 Transformer 等结构学习语言规律，并根据上下文一步步预测和生成下一个 token。
