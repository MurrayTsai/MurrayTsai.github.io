列表标签之有序列表

有序列表

有序列表是一列项目，列表项目使用数字进行标记。

有序列表始于 <ol> 标签。每个列表项始于 <li> 标签。

type属性

<ol> 的属性 type 拥有以下选项：

  1. 1：表示列表项目用数字标号，例如 1, 2, 3...
  2. a：表示列表项目用小写字母标号，例如 a, b, c...
  3. A：表示列表项目用大写字母标号，例如 A, B, C...
  4. i：表示列表项目用小写罗马数字标号，例如 i, ii, iii...
  5. I：表示列表项目用大写罗马数字标号，例如 I, II, III...

有序列表嵌套

列表是可以进行嵌套的。

列表标签之无序列表

无序列表实现

无序列表是一个项目列表，此列项目使用粗体圆点，也就是典型的小黑圆圈进行标记。

无序列表始于 <ul> 标签。每个列表项始于 <li> 标签。

type属性

<ul> 的属性 type 拥有以下选项：

  1. disc：默认实心圆。
  2. circle：空心圆。
  3. square：小方块。
  4. none：不显示。
