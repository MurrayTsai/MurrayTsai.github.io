Form表单

表单在 Web 网页中用来给用户填写信息，从而采集用户信息，使网页具有交互功能。

所有用户输入内容的地方都可以用表单来写，比如登录注册、搜索框等。

表单是由容器和控件组成的。一个表单一般应该包含用户填写信息的输入框、提交按钮等。这些输入框和按钮叫做控件。表单就是容器，它能够容纳各种各样的控件。

属性说明：

  1. action：服务器地址。
  2. name：表单名称。
  3. method：表单提交方式。

method 中 GET 和 POST 的区别：

  1. 数据提交方式不同。GET 提交的数据可以在 URL 中看到，POST 看不到。
  2. GET 一般用于提交少量数据，POST 一般用于提交大量数据。

表单元素

一个完整的表单包含三个基本组成部分：

  1. 表单标签
  2. 表单域，也就是输入框
  3. 表单按钮

表单元素

文本框

文本域通过 <input type="text"> 设定。

当用户要在表单中键入字母、数字等内容时，就会用到文本域。

密码框

密码字段通过 <input type="password"> 来定义。

密码字段字符不会明文显示，而是以星号或圆点代替。

提交按钮

当用户单击确认按钮时，表单的内容会被传送到另一个文件。

表单的 action 属性定义了目的文件的文件名。由 action 属性定义的这个文件，通常会对接收到的输入数据进行相关处理。
