前言

这篇文章整理我对 大语言模型 LLM 的入门理解。

一开始我只知道 LLM 可以生成、分类、改写和总结文本。后来我发现，想真正理解 GPT 这一类模型，就需要继续往下看它背后的结构。

一、什么是大语言模型 LLM？

LLM 的全称是 Large Language Model，中文通常叫 大语言模型。

它是一类通过大量文本数据训练出来的模型。它可以理解文本，也可以生成文本。

这里的“语言”不只包括中文、英文，也包括代码、表格、公式、结构化文本和指令。

简单来说：

大语言模型是一种根据上下文理解和生成文本的 AI 模型。

LLM 常见能力包括：

能力 含义 例子
生成 根据提示写出新内容 写文章、写邮件、写代码
分类 判断文本属于哪一类 判断评论是正面还是负面
改写 保留原意，换一种表达方式 把复杂句改成简单句
总结 提取重点，压缩内容 把长文总结成短文
翻译 在不同语言之间转换 中文翻译成英文
问答 根据问题生成回答 回答学习问题或工作问题

LLM 表面上像是在“回答问题”。但从很多语言模型的训练目标来看，它本质上是在做一件事：

二、从 RNN 到 LSTM：为什么需要更强的序列模型？

在 Transformer 流行之前，处理文本这类序列数据时，经常会用到 RNN。

RNN 的全称是 Recurrent Neural Network，中文叫 循环神经网络。

它的核心思想是：

按顺序处理输入，并把前面步骤的信息传给后面步骤。

比如一句话：

RNN 会一个词一个词地读。每读一个词，它都会更新自己的记忆状态。

可以简单理解为：

但是 RNN 有一个明显问题：

RNN 不擅长处理很长的序列。

原因主要有三个：

  1. 长距离信息容易丢失
    前面的信息要经过很多步才能传到后面。句子越长，信息越容易变弱。

  2. 容易出现梯度问题
    训练长序列时，RNN 容易遇到梯度消失或梯度爆炸。

  3. 并行能力弱
    RNN 要按顺序处理。后一个 token 通常要等前一个 token 处理完。

后来，RNN 被改良为 LSTM。

LSTM 的全称是 Long Short-Term Memory，中文通常叫 长短期记忆网络。

LSTM 加入了“门控机制”，让模型决定：

门 作用
遗忘门 Forget Gate 决定哪些旧信息要丢掉
输入门 Input Gate 决定哪些新信息要写入记忆
输出门 Output Gate 决定当前要输出哪些信息

三、Transformer：现代大语言模型的核心结构

Transformer 的出现，是为了解决传统序列模型的一些问题。

RNN 和 LSTM 都要一步一步读文本，而 Transformer 不再完全依赖循环结构。它通过注意力机制直接建模 token 之间的关系。

Transformer 的两个核心优势是：

  1. 更适合捕捉长距离依赖；
  2. 更适合并行计算。

四、Transformer 核心概念速查表

Transformer 涉及的名词比较多。入门阶段不需要一开始就记公式，可以先理解每个词在流程里负责什么。

名词 中文理解 作用

Embedding 嵌入 / 向量表示 把 token id 转换成向量，让模型能计算语义关系
Positional Encoding 位置编码 给 token 加入顺序信息，让模型知道谁在前谁在后
Self-Attention 自注意力机制 让每个 token 关注同一句话里的其他 token
Multi-Head Attention 多头注意力 从多个角度同时观察 token 之间的关系

Softmax 概率转换函数 把分数转换成概率分布

每个 token 会先变成一个整数编号，也叫 token id。

Encoder 最后的输出不是普通文字，而是一组抽象向量。它们保留了输入文本的词汇、顺序、语法和语义信息。

可以简单理解为：

7. Decoder：负责生成输出

Decoder 的任务是生成输出文本。

在翻译任务中，Encoder 读英文，Decoder 生成中文。

Decoder 生成内容时，会参考两部分信息：

  1. Encoder 对输入文本的理解；
  2. Decoder 自己已经生成过的内容。

Decoder 里还有一个重要结构，叫 Masked Multi-Head Attention。

它的作用是遮住未来信息。

比如模型正在生成第 3 个 token，它只能看第 1 个和第 2 个 token，不能偷看后面的答案。

这样做是为了保证模型按顺序生成。

8. Linear：把向量变成词表分数

Decoder 输出的是向量，但最终模型要选择具体 token。

所以需要 Linear 层。

假设词表里有 50000 个 token，Linear 层就会输出 50000 个分数。

这些分数还不是概率，只是每个 token 的原始得分。

9. Softmax：把分数变成概率

Softmax 的作用是把 Linear 层输出的分数转换成概率分布。

五、GPT 为什么常被说成 Decoder-only？

GPT 的全称是 Generative Pre-trained Transformer。

可以拆开理解：

词 含义
Generative 生成式，说明它可以生成内容
Pre-trained 预训练，说明它先在大量文本上学习语言规律
Transformer 模型架构，说明它基于 Transformer 结构

GPT 主要使用 Decoder-only Transformer。

这意味着 GPT 更关注一件事：

根据已经出现的上下文，预测下一个 token。

流程可以简单理解为：

flowchart LR
    Prompt[输入 Prompt] --> Token[Tokenization]
    Token --> Embedding[Embedding + Positional Encoding]
    Embedding --> MaskedAttention[Masked Self-Attention]
    MaskedAttention --> FFN[Feed Forward]
    FFN --> Linear[Linear]
    Linear --> Softmax[Softmax]
    Softmax --> NextToken[下一个 Token]
    NextToken --> Continue[继续生成]

六、为什么模型会出现幻觉？

幻觉 的英文是 Hallucination。

它指的是：

模型生成了语法通顺、看起来可信，但事实错误或没有依据的内容。

为什么会这样？

因为 LLM 在生成文本时，通常是在根据上下文预测下一个 token。它的目标是生成“看起来最合理”的内容，但这不等于保证每一句都是真的。

幻觉可能来自：

  • 训练数据中有错误；
  • 用户问题缺少足够上下文；
  • 模型不知道自己不知道；
  • 模型为了保持回答连贯，继续生成看似合理的内容；
  • 生成过程本身有概率性。

所以使用 LLM 时，尤其在事实、论文、医学、法律、金融和引用场景中，需要核查。

RNN、LSTM、Transformer 和 GPT 可以这样对比：

模型 核心思想 优点 局限
RNN 按顺序循环处理序列 结构直观，适合序列数据 长序列信息容易丢失，并行能力弱
LSTM 在 RNN 上加入门控记忆 比 RNN 更擅长保留长期信息 仍然按顺序处理，训练效率有限
Transformer 用注意力机制建模 token 关系 长距离建模强，并行能力强 计算量大，需要较多数据和算力
GPT Decoder-only Transformer 擅长文本生成和对话 可能产生幻觉，需要事实核查

前言大语言模型很强。它可以写文章、总结内容、生成代码、回答问题。 但它也有明显限制。 比如： 数据可能过时； 可能编造事实； 数学计算可能不准； 复杂任务中可能遗漏步骤； 面对外部世界信息时，它不一定知道最新情况。 所以，真实应用里不能只依赖模型“直接回答”。 更常见的做法是： 让大语言模型配合外部知识、工具和环境一起工作。 这篇笔记主要整理三个重要方法： 123RAG：解决知识过时和事实依据问题PAL：解决计算和程序执行问题ReAct：解决复杂任务中的推理和行动问题 为什么 AI 会数据过时、编造事实、计算不准？大语言模型的核心能力之一是： 根据上下文预测下一个最可能出现的 token。 这让它很擅长生成自然语言，但也带来一些问题。 1. 数据可能过时模型训练完成后，它的内部知识不会自动实时更新。 如果用户问的是最新政策、最新价格、最新新闻、公司内部文档或个人资料，模型可能不知道。 2. 可能编造事实模型有时会生成看起来很像真的内容，但实际上没有依据。 这类问题通常叫 幻觉，英文是 Hallucination。 比如它可能会： 编造论文引用； 编造公司政策； ...
