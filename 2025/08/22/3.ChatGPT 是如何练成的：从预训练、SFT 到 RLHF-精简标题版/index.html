ChatGPT 是如何练成的：从预训练、SFT 到 RLHF

发表于2025-08-22|更新于2026-06-23|AI
|浏览量:

前言

ChatGPT 看起来像一个会聊天、会写作、会总结、会改代码的 AI 助手。

但它不是一开始就会自然对话。它通常要经过几个阶段的训练，才会从一个“会预测下一个 token 的语言模型”，变成一个“更会按照人类意图回答问题的对话模型”。

可以先用一句话理解：

ChatGPT 先通过海量文本学会语言，再通过人类示范学会回答，最后通过人类反馈学会什么样的回答更好。

ChatGPT 的训练流程总览

ChatGPT 背后是大语言模型，也就是 LLM。

LLM 的基础能力之一是：

根据前面的上下文，预测下一个最可能出现的 token。

比如输入：

它会根据训练中学到的语言规律，一步一步生成后面的内容。

不过，一个只会预测下一个 token 的模型，不一定就是一个好助手。它还需要经过后续训练。

整体流程可以这样理解：

    flowchart TD
    Data[大量文本数据] --> Pretrain[无监督预训练]
    Pretrain --> Base[基座模型<br/>Base Model]

    Demo[高质量问答数据] --> SFT[监督微调<br/>SFT]
    Base --> SFT
    SFT --> SFTModel[SFT 模型<br/>更会按指令回答]

    Ranking[人工排序数据] --> RMTrain[训练奖励模型<br/>Reward Model]
    RMTrain --> RM[奖励模型<br/>判断回答质量]

    SFTModel --> RLHF[RLHF<br/>基于人类反馈的强化学习]
    RM --> RLHF
    RLHF --> ChatGPT[更符合人类偏好的对话模型]

这条路线里有几个关键词：

名词 含义
Base Model 基座模型，预训练后得到的基础语言模型
SFT 监督微调，让模型更会按照指令回答
Reward Model 奖励模型，用来预测回答质量
RLHF 基于人类反馈的强化学习
3H Helpful、Honest、Harmless，也就是有用、诚实、无害

无监督预训练：先得到基座模型

第一阶段是 无监督预训练。

这一阶段会使用非常大规模的文本数据进行训练。数据可能来自书籍、网页、文章、代码、问答内容等。

这里的“无监督”不是说模型没有训练目标，而是说这些数据通常不是人工一条条标好答案的问答数据。模型主要通过文本本身学习语言规律。

模型会不断做这种预测任务。通过大量训练，它会逐渐学到：

  • 词语之间的关系；
  • 句子的语法结构；
  • 常见知识和表达方式；
  • 文本风格；
  • 代码模式；
  • 一些常见推理模式。

这一阶段完成后，会得到一个 基座模型 Base Model。

基座模型可以理解为：

一个语言能力很强，但还不够会聊天的模型。

它已经能生成文本，但不一定擅长稳定回答用户问题。它可能会：

  • 不够像助手；
  • 不一定遵循指令；
  • 回答格式不稳定；
  • 有时续写用户的话，而不是回答用户；
  • 可能生成不安全或不合适的内容；
  • 不知道什么时候应该拒绝。

所以，预训练只是第一步。

另外，预训练成本很高。主要原因是：

成本来源 原因
数据规模大 需要海量文本，还要清洗、筛选和去重
训练时间长 大模型需要处理大量 token
算力成本高 需要大量 GPU 或 AI 加速芯片
工程复杂 训练过程需要存储、网络、调度和稳定性保障

可以总结为：

预训练让模型学会语言和知识，但不一定让模型学会“如何当一个好助手”。

监督微调 SFT：让模型学会按指令回答

第二阶段是 监督微调。

英文是 Supervised Fine-Tuning，简称 SFT。

这一阶段会用人类撰写的高质量对话数据，继续训练基座模型。

数据大概长这样：

也就是说，人类先写出比较理想的回答，然后让模型学习这些回答方式。

SFT 的目标是：

让模型更像一个会按照指令回答问题的助手。

预训练和 SFT 的区别可以这样看：

阶段 使用数据 主要目标 得到结果
无监督预训练 大规模普通文本 学习语言规律和知识 Base Model
监督微调 SFT 高质量问答/对话数据 学会按照人类指令回答 SFT Model

经过 SFT 后，模型会更擅长：

  • 回答问题；
  • 总结内容；
  • 改写文本；
  • 按格式输出；
  • 遵循用户指令；
  • 用更像助手的语气回复。

但是，SFT 模型仍然不完美。

它可能仍然会：

  • 回答看起来合理，但事实错误；
  • 太啰嗦；
  • 没有真正解决用户问题；
  • 不知道哪个回答更符合人类偏好；
  • 在安全问题上处理不够稳定。

所以，还需要继续训练奖励模型。

奖励模型和 RLHF：让模型更符合人类偏好

第三阶段是训练 奖励模型 Reward Model。

奖励模型不是直接负责聊天的模型。它更像一个“评分器”。

它的任务是：

判断一个回答好不好。

训练奖励模型时，通常会准备这样的数据：

比如：

然后系统会用这些排序数据训练奖励模型。

奖励模型学到的是：

它会学习人类更喜欢什么样的回答，比如：

  • 更有帮助；
  • 更真实；
  • 更安全；
  • 更符合用户要求；
  • 结构更清楚；
  • 更少胡说。

奖励模型训练好后，就进入 RLHF 阶段。

RLHF 的全称是 Reinforcement Learning from Human Feedback，意思是 基于人类反馈的强化学习。

流程可以这样理解：

    flowchart TD
    Prompt[用户问题] --> Model[SFT 模型生成回答]
    Model --> Answer[候选回答]
    Answer --> RM[奖励模型评分]
    RM --> Score[Reward 分数]
    Score --> Update[强化学习更新模型]
    Update --> Better[模型更倾向生成高分回答]

这里有一个容易误解的点：

RLHF 不是每一步都让人类实时打分。

更常见的流程是：

  1. 人类先对大量回答做排序；
  2. 用排序数据训练奖励模型；
  3. 强化学习阶段主要让奖励模型自动打分；
  4. 人类继续抽查、评估和改进数据。

原因很简单：

强化学习需要大量反馈。如果每次都让人类手动打分，成本太高，也太慢。

所以，人类反馈主要用于训练奖励模型。奖励模型再参与大规模优化。

训练 ChatGPT 这类对话模型时，一个重要标准是 3H 原则：

Harmless 回答不能帮助造成伤害 不提供违法、危险、伤害性内容

训练流程的简单类比

可以把 ChatGPT 的训练过程类比成培养一个学生。

阶段 类比 对应模型
无监督预训练 学生大量阅读 Base Model
监督微调 SFT 老师示范标准答案 SFT Model
奖励模型 评委比较多个答案好坏 Reward Model
RLHF 学生根据评分反复练习 更符合人类偏好的模型

这个类比可以帮助理解：

容易混淆的点

1. 预训练不是监督微调

预训练主要学习语言规律。监督微调主要学习如何按照指令回答。

2. 基座模型不等于 ChatGPT

基座模型会生成文本，但不一定会稳定对话。

3. SFT 模型不等于最终模型

SFT 模型已经更会回答，但还需要人类偏好数据和强化学习优化。

4. 奖励模型不是聊天模型

奖励模型主要负责评分，不是直接负责和用户对话。

5. RLHF 不是让模型永远正确

RLHF 让模型更符合人类偏好，但不能保证所有事实都正确。模型仍然可能出现幻觉、偏见或误判。

前言 最近我在整理 AI 相关概念时，发现很多词看起来很像，但它们其实不是同一层级的东西。 比如： AIGC 更偏向“AI 生成出来的内容”。 生成式 AI 更偏向“能够生成内容的技术或系统”。 机器学习是 AI 的一种实现方式。 深度学习是机器学习中的一种重要方法。 大语言模型，也就是 LLM，是深度学习和生成式 AI 中非常重要的一类模型。 所以，这篇笔记主要用来梳理这些概念之间的关系。 一、AIGC 是什么？AIGC 的全称是 AI Generated Content，意思是“由人工智能生成的内容”。 这里的“内容”可以包括很多类型，比如： 文本：文章、摘要、故事、邮件、论文大纲； 代码：函数、脚本、网页组件、自动化工具； 图片：插画、海报、头像、产品图； 音频：配音、音乐、音效； 视频：短片、动画、数字人视频。 所以，AIGC 不是某一种具体模型。它更强调的是 AI 生成出来的结果。 可以简单理解为： 只要内容主要由 AI 生成，就可以被称为 AIGC。 二、生成式 AI 是什么？生成式 AI 的英文是 Generative AI。它指的是能够根据已有...
